# Dataset Catalogue

The runtime catalogue is maintained at `docs/dataset_catalog.json` and is loaded by `scripts/clinical_repository_copy.py`.

`dataset_catalog.json` in this folder is kept as a synchronized human-facing copy for the dataset-catalog folder. Update both copies together if the registered dataset IDs or source table mappings change.

`dataset_id_mapping.md` provides the human-readable dataset ID mapping.
